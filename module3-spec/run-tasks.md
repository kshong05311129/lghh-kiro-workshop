# 🚀 (보너스) Task 실행하기

> ⚠️ **이 페이지는 보너스 콘텐츠입니다.** 시간이 남거나 호기심이 있으신 분만 진행하세요! Task 실행은 15\~20분 이상 걸릴 수 있습니다.

> 🎯 Spec에 정의된 Task를 하나씩 실행해서 도구를 완성합시다!

## Task 실행이란?

Spec에 정의된 작업 목록(tasks.md)을 AI가 **하나씩 순서대로** 실행하는 것입니다.

### 비유

> 🧴 레시피(Spec)를 보고 요리를 단계별로 하는 것과 같습니다:
>
> 1. 재료 준비 (HTML 구조)
> 2. 밑간 하기 (입력 폼)
> 3. 조리하기 (로직)
> 4. 플레이팅 (디자인)
> 5. 서빙 (완성!)

## Step 1: 첫 번째 Task 실행

Kiro에서 Task를 실행하는 방법:

**방법 A:** `.kiro/specs/competitor-analysis/tasks.md` 파일을 열고, 첫 번째 Task 옆의 ▶️ 버튼 클릭

**방법 B:** 채팅에서 직접 요청

```
competitor-analysis spec의 Task 1을 실행해줘
```

## Step 2: 순차적으로 실행

각 Task가 완료되면 다음 Task를 실행합니다:

```
Task 2 실행해줘
```

> 💡 **팁**: 각 Task 완료 후 결과를 확인하고, 문제가 있으면 바로 수정을 요청할 수 있습니다!

### Task 실행 중 수정이 필요하면?

```
방금 만든 입력 폼에서 "카테고리" 필드를 드롭다운으로 바꿔줘.
선택지: 에센스, 크림, 토너, 로션, 마스크팩
```

## Step 3: 전체 Task 한번에 실행

시간이 부족하면 전체를 한번에 실행할 수도 있습니다:

```
나머지 Task 전부 실행해줘
```

## Step 5: 최종 개선

결과물을 보고 추가 개선:

```
비교 테이블 아래에 "종합 분석" 섹션을 추가해줘.
자사 제품의 강점과 약점을 3줄로 요약해서 보여줘.
```

## 💡 Vibe Coding vs Spec 비교 (체감)

| 항목     | Vibe Coding       | Spec 기반             |
| ------ | ----------------- | ------------------- |
| 소요시간   | 빠름 (바로 결과)        | 설계 시간 필요하지만 체계적     |
| 결과물 품질 | 간단한 건 OK, 복잡하면 빠짐 | 모든 기능이 빠짐없이 구현      |
| 수정 용이성 | 누적되면 꼬일 수 있음      | Task 단위로 깔끔하게 수정    |
| 추천 상황  | 프로토타입, 간단한 도구     | 여러 기능이 있는 완성도 높은 도구 |

## 🔧 트러블슈팅

### "Task 실행 버튼이 안 보여요"

* `tasks.md` 파일을 직접 열어보세요
* 채팅에서 "Task N 실행해줘"로 직접 요청

### "이전 Task 결과가 사라졌어요"

* Kiro는 자동으로 이전 결과를 유지합니다
* 문제가 있다면: "competitor-analysis.html 현재 상태 보여줘"

### "차트가 안 그려져요"

* 인터넷 연결 확인 (Chart.js CDN 필요)
* 브라우저 콘솔(F12)에서 에러 확인
