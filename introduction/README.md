## 🤔 Kiro IDE가 뭔가요?

**Kiro** = AI가 내장된 코딩 도구

일반인 언어로 설명하면:

| 일반 도구 | Kiro |
|-----------|------|
| 한글/워드 | AI가 대신 코딩해주는 편집기 |
| 엑셀에서 수식 입력 | AI에게 "이거 만들어줘" 하면 완성 |

> 💡 **핵심**: 여러분은 코딩을 배우는 게 아닙니다. AI에게 **"뭘 만들어줘"** 라고 말하는 법을 배우는 겁니다!
