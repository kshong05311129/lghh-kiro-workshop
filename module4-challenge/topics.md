## 주제 1: 마케팅 카피 생성기 ⭐

### 설명
제품 특징을 입력하면 SNS/광고용 마케팅 카피를 자동 생성하는 도구

### 프롬프트 예시

```
마케팅 카피 생성기 HTML을 만들어줘.

입력:
- 제품명
- 핵심 성분
- 타겟 연령대
- 제품 컨셉 (1줄)
- 톤앤매너 (럭셔리/트렌디/자연친화)

출력:
- SNS 게시글용 카피 (3가지 버전)
- 광고 헤드라인 (2가지)
- 해시태그 추천 (5개)

예쁘게 카드 형식으로 보여주고, 복사 버튼 넣어줘.
Tailwind CSS CDN 사용.
```

## 주제 2: 타겟 고객 페르소나 카드 ⭐⭐

### 설명
타겟 고객 정보를 입력하면 시각적인 페르소나 카드를 생성

### 프롬프트 예시

```
타겟 고객 페르소나 카드 생성기 HTML을 만들어줘.

입력:
- 이름 (가상)
- 연령대
- 직업
- 라이프스타일 키워드 (3개)
- 피부 고민
- 선호 브랜드 느낌 (럭셔리/합리적/자연주의)
- 월 화장품 지출액

출력:
- 프로필 카드 형태로 시각화
- 라이프스타일 태그 배지
- 추천 제품 카테고리 제안
- "이 고객이 좋아할 제품" 키워드

고급스러운 디자인, Tailwind CSS CDN 사용.
```

## 주제 3: 제품 런칭 타임라인 ⭐⭐

### 설명
제품 출시 일정을 입력하면 간트차트 형태의 타임라인 생성

### 프롬프트 예시

```
제품 런칭 타임라인 생성기 HTML을 만들어줘.

입력 (여러 단계 추가 가능):
- 단계명 (예: 컨셉 기획, 처방 개발, 패키지 디자인, 생산, 마케팅, 런칭)
- 시작일
- 종료일
- 담당팀

출력:
- 간트차트 형태의 타임라인 (컬러 바)
- 전체 일정 요약 (총 소요기간, 남은 일수)
- 각 단계별 진행률 표시

Chart.js CDN 사용, Tailwind CSS CDN.
D-Day 표시 기능 포함.
```

## 주제 5: NPL 보고서 요약기 ⭐⭐⭐

### 설명
제품 정보를 입력하면 NPL Pre-Start의 Strategic Fit 섹션을 자동 요약 생성

### 프롬프트 예시

```
NPL Strategic Fit 요약 생성기 HTML을 만들어줘.

입력:
- Brand (브랜드명)
- Franchise (라인명)
- Format (제품 유형)
- Volume (용량)
- Ambition (Y1 매출 목표)
- Description (제품의 역할 및 목적)
- Portfolio Role (Innovation/Renewal/Promotion)

출력:
- 깔끔한 보고서 형태의 Strategic Fit 요약
- 입력 정보 기반으로 "이 제품의 시장 포지셔닝" 한줄 요약
- 체크리스트 형태로 "다음 단계에서 필요한 정보" 표시
- PDF스러운 디자인 (인쇄 가능한 느낌)

Tailwind CSS CDN 사용, 깔끔한 비즈니스 디자인.
```

## 주제 7: 뷰티 유형 테스트 ⭐

### 설명
몇 가지 질문에 답하면 "나는 어떤 스킨케어 유형"인지 결과 카드를 보여주는 테스트

### 프롬프트 예시

```
뷰티 유형 테스트 HTML을 만들어줘.

기능:
- 스킨케어 습관/취향에 관한 질문 5개 (객관식, 각 2~3개 선택지)
- 답변 조합에 따라 4~5가지 유형 중 하나로 결과 판정
  (예: "미니멀리스트형", "성분 덕후형", "트렌드 얼리어답터형", "감성 힐링형")
- 결과 화면에 유형 이름, 한줄 설명, 어울리는 제품 카테고리, 어울리는 이모지 표시
- "다시 하기" 버튼

디자인:
- 질문마다 화면이 전환되는 느낌 (진행 바 표시)
- 결과 카드는 SNS 공유하고 싶게 예쁘게
- Tailwind CSS CDN 사용
```

## 주제 8: 오늘의 뷰티 운세 ⭐

### 설명
오늘 날짜/기분을 입력하면 오늘의 추천 컬러·제품·루틴을 운세처럼 재치있게 알려주는 도구

### 프롬프트 예시

```
오늘의 뷰티 운세 HTML을 만들어줘.

입력:
- 오늘 기분 (버튼으로 선택: 상쾌함/피곤함/설렘/차분함 등)
- 오늘 날씨 (맑음/흐림/비/눈)

출력:
- 오늘의 행운 컬러 (립/아이섀도우 색상 하나, 색상 스와치 표시)
- 오늘의 추천 스킨케어 한 줄 팁
- 오늘의 뷰티 운세 멘트 (예: "오늘은 과감한 컬러가 잘 받는 날!")
- 재미있고 유머러스한 톤앤매너로

디자인:
- 운세 카드/포춘쿠키 느낌
- Tailwind CSS CDN 사용
```

## 주제 9: 향수 조합 이름 짓기 ⭐

### 설명
좋아하는 향/느낌을 입력하면 그럴듯한 향수 이름과 감성 카피를 지어주는 도구

### 프롬프트 예시

```
향수 이름 짓기 생성기 HTML을 만들어줘.

입력:
- 좋아하는 향 계열 (플로럴/우디/시트러스/머스크 등, 복수 선택 가능)
- 떠오르는 계절 또는 시간대 (봄/여름/가을/겨울, 아침/밤)
- 원하는 느낌 키워드 (자유 입력, 예: "첫사랑", "여행", "차분함")

출력:
- 그럴듯한 향수 이름 3가지 제안 (영문/국문 혼용 느낌)
- 각 이름에 어울리는 한 줄 감성 카피
- 예상되는 향의 구성(탑/미들/베이스 노트) 간단 설명

디자인:
- 향수병 일러스트 느낌의 카드 UI
- Tailwind CSS CDN 사용
```

## 주제 10: 레트로 광고 포스터 생성기 ⭐⭐

### 설명
제품 정보를 입력하면 옛날 느낌 나는 빈티지 스타일 광고 포스터를 HTML로 생성

### 프롬프트 예시

```
레트로 광고 포스터 생성기 HTML을 만들어줘.

입력:
- 제품명
- 핵심 카피 문구 (1줄)
- 컨셉 연도 느낌 (1970년대/1980년대/1990년대 중 선택)

출력:
- 선택한 연도 감성이 느껴지는 빈티지 광고 포스터 스타일 페이지
  (그 시대 느낌의 색감, 레이아웃, 장식 요소)
- 제품명과 카피가 큼직하게 들어간 레이아웃
- "다운로드" 버튼 (이미지로 저장하는 척만 해도 됨)

디자인:
- 실제 옛날 잡지 광고처럼 보이도록 폰트/색감/테두리 신경써서
- Google Fonts CDN 사용 가능
```

## 주제 11: 기분 컬러 매칭기 ⭐

### 설명
오늘 기분이나 날씨를 입력하면 어울리는 립/네일 컬러를 추천해주는 도구

### 프롬프트 예시

```
기분 컬러 매칭기 HTML을 만들어줘.

입력:
- 오늘 기분 키워드 (자유 입력 또는 버튼 선택)
- 립 or 네일 중 선택

출력:
- 어울리는 컬러 3가지 추천 (색상 스와치 + 컬러명 + 색상 코드)
- 각 컬러를 추천하는 이유 한 줄
- "이 컬러 조합, 이런 스타일에 잘 어울려요" 코디 팁

디자인:
- 컬러 스와치가 크고 선명하게 보이도록
- Tailwind CSS CDN 사용
```
