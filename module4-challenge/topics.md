## 주제 1: 마케팅 카피 생성기 ⭐

### 설명
제품 특징을 입력하면 SNS/광고용 마케팅 카피를 자동 생성하는 도구

### 프롬프트 예시

```
마케팅 카피 생성기 HTML을 만들어줘.

입력:
- 제품명
- 핵심 성분
- 타겟 연령대
- 제품 컨셉 (1줄)
- 톤앤매너 (럭셔리/트렌디/자연친화)

출력:
- SNS 게시글용 카피 (3가지 버전)
- 광고 헤드라인 (2가지)
- 해시태그 추천 (5개)

예쁘게 카드 형식으로 보여주고, 복사 버튼 넣어줘.
Tailwind CSS CDN 사용.
```

## 주제 2: 타겟 고객 페르소나 카드 ⭐⭐

### 설명
타겟 고객 정보를 입력하면 시각적인 페르소나 카드를 생성

### 프롬프트 예시

```
타겟 고객 페르소나 카드 생성기 HTML을 만들어줘.

입력:
- 이름 (가상)
- 연령대
- 직업
- 라이프스타일 키워드 (3개)
- 피부 고민
- 선호 브랜드 느낌 (럭셔리/합리적/자연주의)
- 월 화장품 지출액

출력:
- 프로필 카드 형태로 시각화
- 라이프스타일 태그 배지
- 추천 제품 카테고리 제안
- "이 고객이 좋아할 제품" 키워드

고급스러운 디자인, Tailwind CSS CDN 사용.
```

## 주제 3: 제품 런칭 타임라인 ⭐⭐

### 설명
제품 출시 일정을 입력하면 간트차트 형태의 타임라인 생성

### 프롬프트 예시

```
제품 런칭 타임라인 생성기 HTML을 만들어줘.

입력 (여러 단계 추가 가능):
- 단계명 (예: 컨셉 기획, 처방 개발, 패키지 디자인, 생산, 마케팅, 런칭)
- 시작일
- 종료일
- 담당팀

출력:
- 간트차트 형태의 타임라인 (컬러 바)
- 전체 일정 요약 (총 소요기간, 남은 일수)
- 각 단계별 진행률 표시

Chart.js CDN 사용, Tailwind CSS CDN.
D-Day 표시 기능 포함.
```

## 주제 4: 성분 비교 분석기 ⭐⭐

### 설명
여러 제품의 성분을 입력하면 비교 인포그래픽 생성

### 프롬프트 예시

```
화장품 성분 비교 분석기 HTML을 만들어줘.

입력 (최대 3개 제품):
- 제품명
- 주요 성분 목록 (쉼표로 구분)
- 성분 카테고리 (보습/미백/항노화/진정)

출력:
- 벤 다이어그램 형태로 공통 성분 / 고유 성분 표시
- 성분 카테고리별 레이더 차트
- 각 성분의 효능 간단 설명 tooltip

Chart.js CDN, Tailwind CSS CDN 사용.
```

## 주제 5: NPL 보고서 요약기 ⭐⭐⭐

### 설명
제품 정보를 입력하면 NPL Pre-Start의 Strategic Fit 섹션을 자동 요약 생성

### 프롬프트 예시

```
NPL Strategic Fit 요약 생성기 HTML을 만들어줘.

입력:
- Brand (브랜드명)
- Franchise (라인명)
- Format (제품 유형)
- Volume (용량)
- Ambition (Y1 매출 목표)
- Description (제품의 역할 및 목적)
- Portfolio Role (Innovation/Renewal/Promotion)

출력:
- 깔끔한 보고서 형태의 Strategic Fit 요약
- 입력 정보 기반으로 "이 제품의 시장 포지셔닝" 한줄 요약
- 체크리스트 형태로 "다음 단계에서 필요한 정보" 표시
- PDF스러운 디자인 (인쇄 가능한 느낌)

Tailwind CSS CDN 사용, 깔끔한 비즈니스 디자인.
```

## 주제 6: 브랜드 가이드 검색 도우미 ⭐⭐

### 설명
`data/beauty-brand-guide.md` 문서에서 검색어와 관련된 내용을 찾아서 보여주는 도구

### 프롬프트 예시

```
브랜드 가이드 검색 도우미 HTML을 만들어줘.

기능:
- 검색어를 입력하면 data/beauty-brand-guide.md에서 관련 내용을 찾아서 보여줌
- 카테고리별 필터 (브랜드 포지셔닝, 표현 가이드라인, 고객 대응 원칙)
- 검색 결과를 카드 형태로 보여줌
- 자주 찾는 항목 TOP 5 표시

디자인:
- LG생활건강 브랜드 색상 (메인 #E4007F, 서브 #1B1B1B, 포인트 #C5A572)
- 깔끔하고 모던한 디자인
- 모바일에서도 잘 보이게

데이터:
- data/beauty-brand-guide.md 파일의 내용을 검색 대상으로 사용
```
