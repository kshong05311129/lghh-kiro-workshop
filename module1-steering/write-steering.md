## 실습: 뷰티 제품 분석 어시스턴트 만들기

### Step 1: AI에게 Steering 생성 요청

Kiro 채팅창에 아래를 **그대로** 입력하세요:

```
.kiro/steering/product.md 파일을 만들어줘. 내용은 아래와 같아:

---
# 뷰티 제품 분석 어시스턴트

## 역할
너는 LG생활건강 뷰티 제품 분석 전문가야.
화장품 시장 분석, 제품 비교, 마케팅 인사이트 도출을 도와줘.

## 맥락
- 한국 화장품(K-Beauty) 시장에서 일하고 있어
- 주요 브랜드: 후, 숨37, 오휘, 빌리프, CNP, 더페이스샵
- 주요 카테고리: 스킨케어, 메이크업, 바디케어, 헤어케어

## 참고 자료
- data/beauty-brand-guide.md 파일을 참고 자료로 사용한다

## 규칙
1. 항상 한국어로 답변한다
2. 제품 분석 시 성분, 타겟, 가격대, 포지셔닝을 포함한다
3. 경쟁사 언급 시 객관적 데이터 기반으로 비교한다
4. 소비자 관점과 마케터 관점을 모두 고려한다
5. 코드 작성 시 단일 HTML 파일로 만든다 (외부 설치 불필요)

## 응답 형식
- 간결하고 핵심 위주로 답변
- 필요시 표 형식 활용
- 수치가 있으면 시각화 제안
```

### Step 2: 파일 생성 확인

왼쪽 파일 탐색기에서 확인:

```
kiro-beauty-workshop/

```

### Step 3: Steering 효과 테스트

이제 채팅에서 이렇게 물어보세요:

```
"후" 브랜드 제품을 안내할 때 톤앤매너가 어때야 해?
```

> 💡 `data/beauty-brand-guide.md`를 참고 자료로 지정해뒀기 때문에, AI가 문서에 있는 "품격 있고 격조 높은 표현" 같은 실제 가이드 내용을 근거로 답변합니다. AI의 일반 지식이 아니라 **우리가 준 문서 기반**이라 매번 같은 기준으로 답한다는 게 핵심이에요.

### Step 4: 비교해보기

만약 Steering(+참고 자료) 없이 같은 질문을 하면 어떨까요?

* Steering 있음: "후는 궁중 한방 럭셔리 브랜드로, 품격 있고 격조 높은 표현을 사용하며..." (문서 기반, 일관됨)
* Steering 없음: "후(后)는 한국 화장품 브랜드입니다..." (일반적, 매번 다를 수 있음)

> 🎁 **궁금하신 분은 직접 비교해보세요**: `.kiro/steering` 폴더 이름을 잠깐 `steering-off` 같은 걸로 바꾼 뒤 새 대화에서 같은 질문을 해보면, 방금 받은 답변과 확실히 달라지는 걸 직접 확인할 수 있습니다. 확인 후에는 폴더 이름을 다시 `steering`으로 되돌려주세요.
