# 반복 개선하기

> 🎯 AI와 대화하면서 결과물을 점점 좋게 만들어봅시다!

## 핵심 개념: 대화형 개선

Vibe Coding의 핵심은 **한 번에 완벽하게 만들려고 하지 않는 것**입니다.

```
첫 요청 → 60점짜리 결과 → "이거 수정해줘" → 80점 → "여기도 바꿔줘" → 95점! 🎉
```

### 뷰티 업계 비유

> 제품 패키지 디자인할 때도 "1차 시안 → 피드백 → 2차 → 피드백 → 최종"이죠? AI 코딩도 똑같습니다!

## 실습: 제품 카드 진화시키기

아까 만든 `product-card.html`을 단순 디자인 개선을 넘어, **AI가 콘텐츠까지 만들어주는 카드**로 발전시켜봅시다.

### 개선 1: 브랜드 색상 적용

채팅에 입력:

```
product-card.html에서 카드 디자인을 좀 더 고급스럽게 바꿔줘:
- 배경: 다크 그라데이션 (#1a1a2e → #16213e)
- 포인트 색상: 골드 (#C5A572)
- 브랜드명은 골드 색으로
- 가격은 크게, 볼드로
```

### 개선 2: 브랜드 가이드 기반 마케팅 카피 자동 생성

> 💡 이 단계는 `data/beauty-brand-guide.md`를 사용합니다. 없다면 [환경 설정](../introduction/getting-started.md) Step 6에서 먼저 받아두세요.

```
data/beauty-brand-guide.md 파일을 참고해서, 카드에 "AI 카피 생성" 버튼을 추가해줘.
버튼을 누르면 입력된 브랜드/제품 정보를 바탕으로:
- 해당 브랜드의 톤앤매너 가이드에 맞는 SNS용 마케팅 카피 3가지 버전을 생성
- 각 카피 아래 "복사" 버튼 추가
- 카피는 카드 아래쪽에 리스트로 표시

디자인은 지금의 다크 그라데이션(#1a1a2e → #16213e) + 골드(#C5A572) 톤을 그대로 유지해줘.
버튼도 골드 테두리에 골드 텍스트로, 배경색과 잘 어울리게 만들어줘.
```

> 💡 이제 카드가 단순 정보 표시를 넘어서, **문서를 참고해 실제 업무 산출물(카피)까지 만들어주는 도구**가 됐습니다.

<figure><img src="../.gitbook/assets/image (6) (1).png" alt=""><figcaption></figcaption></figure>

### 개선 3: 카드 Flip 애니메이션

```
카드에 클릭하면 뒤집히는 flip 애니메이션을 추가해줘.
- 앞면: 브랜드, 제품명, 가격 (지금 모습 그대로)
- 뒷면: 핵심 성분 상세 설명 + 방금 만든 AI 카피 3가지
- 카드 클릭 또는 "자세히 보기" 버튼으로 뒤집히게
- CSS 3D transform으로 부드럽게 전환

뒷면도 앞면과 똑같은 다크 그라데이션 + 골드 톤을 유지해줘.
뒷면 테두리에 골드 라인을 살짝 넣어서 앞뒤가 하나의 세트처럼 보이게 해줘.
```

### 핵심 원칙

1. **구체적으로** 말하기 (색상 코드, 크기, 위치)
2. **한 번에 하나씩** 수정하기 (여러 개 한꺼번에 ❌)
3. **결과를 확인**하고 다음 요청하기
