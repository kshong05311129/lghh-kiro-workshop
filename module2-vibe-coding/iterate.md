# 반복 개선하기

> 🎯 AI와 대화하면서 결과물을 점점 좋게 만들어봅시다!

## 핵심 개념: 대화형 개선

Vibe Coding의 핵심은 **한 번에 완벽하게 만들려고 하지 않는 것**입니다.

```
첫 요청 → 60점짜리 결과 → "이거 수정해줘" → 80점 → "여기도 바꿔줘" → 95점! 🎉
```

### 뷰티 업계 비유

> 제품 패키지 디자인할 때도 "1차 시안 → 피드백 → 2차 → 피드백 → 최종"이죠?
> AI 코딩도 똑같습니다!

## 실습: 제품 카드 개선하기

아까 만든 `product-card.html`을 더 좋게 만들어봅시다.

### 개선 1: 브랜드 색상 적용

채팅에 입력:

```
product-card.html에서 카드 디자인을 좀 더 고급스럽게 바꿔줘:
- 배경: 다크 그라데이션 (#1a1a2e → #16213e)
- 포인트 색상: 골드 (#C5A572)
- 브랜드명은 골드 색으로
- 가격은 크게, 볼드로
```

> 📸 *스크린샷 삽입: 다크+골드 톤으로 개선된 카드*

### 개선 2: 기능 추가

```
카드 아래에 "이미지로 저장" 버튼을 추가해줘.
html2canvas CDN을 사용해서 카드를 PNG로 다운로드할 수 있게 해줘.
```

> 📸 *스크린샷 삽입: 이미지로 저장한 카드 결과물*

### 개선 3: 여러 장 생성

```
한 번에 여러 제품을 입력할 수 있게 바꿔줘.
- "제품 추가" 버튼을 누르면 입력 폼이 하나 더 생기고
- "전체 생성" 버튼을 누르면 카드가 나란히 표시되게
- 최대 4개까지
```

## 💡 프롬프트 팁

| 이렇게 하면 ❌ | 이렇게 하면 ✅ |
|----------------|----------------|
| "좀 더 예쁘게" | "배경을 #1a1a2e로, 폰트를 Pretendard로 바꿔줘" |
| "잘 안 돼" | "생성 버튼 누르면 아무 반응이 없어. 콘솔 에러 확인해줘" |
| "다시 해줘" | "카드 너비를 400px로 고정하고, 그림자 효과 추가해줘" |

### 핵심 원칙

1. **구체적으로** 말하기 (색상 코드, 크기, 위치)
2. **한 번에 하나씩** 수정하기 (여러 개 한꺼번에 ❌)
3. **결과를 확인**하고 다음 요청하기
