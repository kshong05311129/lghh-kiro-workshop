# 파일 컨텍스트

> 🎯 AI에게 참고 자료를 주면 더 정확한 결과를 만들어줍니다!

## 핵심 개념

AI에게 "이 파일 참고해서 만들어줘"라고 하면, 파일 내용을 이해하고 활용합니다.

### 비유

| 상황 | 파일 컨텍스트 없이 | 파일 컨텍스트 있으면 |
|------|-------------------|---------------------|
| 비유 | "아무 자료 없이 보고서 써" | "이 데이터 보고 보고서 써" |
| 결과 | 일반적인 내용 | 실제 데이터 기반 결과 |

## 실습 준비: 샘플 데이터 다운로드

채팅에 아래를 입력하세요:

```
아래 URL의 내용을 다운로드해서 data/lghh_products_2026.csv 파일로 저장해줘
https://raw.githubusercontent.com/kshong05311129/lghh-kiro-workshop/main/data/lghh_products_2026.csv
```

> 💡 이 파일은 2026년 상반기 LG생활건강 가상 제품 데이터입니다.

## 실습: 데이터 기반 제품 카드 생성

### Step 1: 데이터 확인

채팅에 입력:

```
data/lghh_products_2026.csv 파일 내용을 보여줘. 어떤 컬럼이 있는지 정리해줘.
```

### Step 2: CSV 데이터 활용하여 도구 만들기

```
data/lghh_products_2026.csv 파일을 참고해서,
제품 데이터를 드롭다운으로 선택하면 자동으로 제품 소개 카드가 생성되는 HTML을 만들어줘.

요구사항:
- CSV의 제품 목록이 드롭다운에 표시
- 제품 선택하면 해당 정보로 카드 자동 생성
- 카드에 브랜드, 제품명, 카테고리, 핵심 성분, 가격, 타겟 표시
- 파일명: product-card-auto.html
- CSV 데이터는 JavaScript 배열로 HTML 안에 임베딩
```

### Step 3: 결과 확인

1. `product-card-auto.html`을 브라우저에서 열기
2. 드롭다운에서 제품 선택
3. 카드가 자동 생성되는지 확인! 🎉

> 📸 *스크린샷 삽입: CSV 드롭다운 선택으로 자동 생성된 카드*

## 💡 파일 컨텍스트 활용 팁

### 방법 1: 채팅에서 직접 언급
```
data/lghh_products_2026.csv 참고해서 ~해줘
```

### 방법 2: @ 멘션 (Kiro 기능)
채팅에서 `@`를 입력하면 파일 목록이 나타납니다. 파일을 선택하면 AI가 자동으로 참고합니다.

### 방법 3: 파일을 열어둔 상태에서 요청
파일 탭을 열어둔 상태에서 요청하면, AI가 해당 파일을 맥락으로 활용합니다.
