# 파일 컨텍스트

> 🎯 AI에게 참고 자료를 주면 더 정확한 결과를 만들어줍니다!

## 핵심 개념

AI에게 "이 파일 참고해서 만들어줘"라고 하면, 파일 내용을 이해하고 활용합니다.

### 비유

| 상황 | 파일 컨텍스트 없이 | 파일 컨텍스트 있으면 |
|------|-------------------|---------------------|
| 비유 | "아무 자료 없이 보고서 써" | "이 데이터 보고 보고서 써" |
| 결과 | 일반적인 내용 | 실제 데이터 기반 결과 |

## 실습 준비: 샘플 데이터 확인

[환경 설정](../introduction/getting-started.md)에서 다운로드한 `data/lghh_products_2026.csv` 파일이 있는지 확인하세요.

없다면 채팅에 입력:

```
아래 URL의 내용을 다운로드해서 data/lghh_products_2026.csv 파일로 저장해줘
https://raw.githubusercontent.com/kshong05311129/lghh-kiro-workshop/main/data/lghh_products_2026.csv
```

> 💡 이 파일은 2026년 상반기 LG생활건강 가상 제품 데이터입니다.

## 실습: 인터랙티브 제품 카탈로그 만들기

이번엔 카드 한 장이 아니라, **CSV 전체 제품을 검색하고 필터링할 수 있는 카탈로그**를 만들어봅니다.

### Step 1: 데이터 확인

채팅에 입력:

```
data/lghh_products_2026.csv 파일 내용을 보여줘. 어떤 컬럼이 있는지 정리해줘.
```

### Step 2: 카탈로그 요청

```
data/lghh_products_2026.csv 파일을 참고해서 인터랙티브 제품 카탈로그 HTML을 만들어줘.

기능:
- CSV의 전체 제품을 카드 그리드로 표시
- 상단에 실시간 검색창 (입력하는 대로 제품명/브랜드로 즉시 필터링)
- 브랜드별 필터 칩 (클릭하면 토글, 여러 개 동시 선택 가능)
- 가격 낮은순/높은순 정렬 버튼
- 카드를 클릭하면 상세 모달 팝업 (성분, 타겟, 출시월, 가격대 전체 표시)
- 검색/필터 결과가 없을 때 "해당하는 제품이 없습니다" 안내 문구

디자인:
- LG생활건강 브랜드 컬러 (메인 #E4007F, 포인트 #C5A572)
- Tailwind CSS CDN 사용
- 반응형 그리드 레이아웃 (모바일에서도 잘 보이게)

기술 조건:
- 단일 HTML 파일
- CSV 데이터는 JavaScript 배열로 HTML 안에 임베딩
- 파일명: product-catalog.html
```

### Step 3: 결과 확인

1. `product-catalog.html`을 브라우저에서 열기
2. 검색창에 브랜드명이나 제품명을 입력해서 실시간 필터링 확인
3. 브랜드 필터 칩을 클릭해서 선택/해제 확인
4. 가격 정렬 버튼 클릭해서 순서 바뀌는지 확인
5. 카드 클릭해서 상세 모달이 뜨는지 확인 🎉

> 📸 *스크린샷 삽입: 검색/필터 적용된 카탈로그 화면*

> 📸 *스크린샷 삽입: 상세 모달 팝업 화면*

### Step 4: 레벨업 — 나만의 뷰티 컬렉션 보드 (보너스)

시간이 남으면, 카탈로그를 "그냥 보는 도구"에서 "내가 쓰는 도구"로 발전시켜봅시다.

> ⚠️ 지금까지 만든 도구는 새로고침하거나 브라우저를 껐다 켜면 입력한 내용이 사라집니다.
> 별도 DB 없이도, 브라우저의 `localStorage`를 쓰면 껐다 켜도 데이터가 그대로 남습니다!

#### 4-1. 즐겨찾기 + 메모 (localStorage 자동 저장)

```
제품 카드마다 ❤️ 즐겨찾기 버튼과 메모 입력창을 추가해줘.
- 즐겨찾기 누르면 하트가 채워지고, 상단에 "즐겨찾기만 보기" 토글 버튼 추가
- 메모는 자유롭게 입력 가능 (예: "다음 시즌 후보")
- 즐겨찾기 상태와 메모는 localStorage에 저장해서, 브라우저를 껐다 켜도 유지되게 해줘
```

> 📸 *스크린샷 삽입: 즐겨찾기 + 메모 기능*

#### 4-2. 드래그 앤 드롭 우선순위 보드

```
즐겨찾기한 제품들로 "이번 시즌 추천 순위" 보드를 만들어줘.
- SortableJS CDN을 사용해서 카드를 마우스로 드래그해서 순서를 바꿀 수 있게
- 순서가 바뀌면 1위, 2위, 3위... 순번이 자동으로 갱신
- 순서도 localStorage에 저장해서 유지되게 해줘
```

> 📸 *스크린샷 삽입: 드래그로 순서를 바꾼 우선순위 보드*

#### 4-3. 내보내기 / 불러오기 (백업)

```
"내 컬렉션 내보내기" 버튼을 추가해줘. 누르면 즐겨찾기/메모/순위 데이터를
JSON 파일로 다운로드하게 해줘.
"불러오기" 버튼도 추가해서, 내보낸 JSON 파일을 다시 업로드하면
데이터가 복원되게 해줘. (다른 컴퓨터로 옮기거나 동료와 공유할 때 사용)
```

> 💡 이제 이 카탈로그는 DB 없이도 "내 데이터가 안전하게 남아있는" 개인 도구가 됐습니다. 브라우저가 곧 작은 데이터베이스인 셈이죠!

#### 그 외 추가로 해볼 수 있는 것들

```
필터링된 제품 개수를 상단에 "총 N개 제품"으로 표시해줘
```

```
다크모드 토글 버튼을 추가해줘
```

## 💡 파일 컨텍스트 활용 팁

### 방법 1: 채팅에서 직접 언급
```
data/lghh_products_2026.csv 참고해서 ~해줘
```

### 방법 2: @ 멘션 (Kiro 기능)
채팅에서 `@`를 입력하면 파일 목록이 나타납니다. 파일을 선택하면 AI가 자동으로 참고합니다.

### 방법 3: 파일을 열어둔 상태에서 요청
파일 탭을 열어둔 상태에서 요청하면, AI가 해당 파일을 맥락으로 활용합니다.

## 🔧 트러블슈팅

### "CSV 파일이 안 열려요"
```
data 폴더에 lghh_products_2026.csv 파일이 있는지 확인해줘
```

### "검색이나 필터가 안 돼요"
```
product-catalog.html에서 CSV 데이터가 제대로 임베딩됐는지, 검색/필터 로직에 에러가 없는지 확인하고 수정해줘
```

### "카드가 하나도 안 보여요"
```
브라우저 콘솔(F12)에서 에러 메시지를 확인하고, product-catalog.html을 고쳐줘
```
