# Module 2: Vibe Coding

> ⏱️ 소요시간: 약 30분

## 🎯 이번 모듈의 목표

AI와 **대화하면서** 실제로 작동하는 도구를 만들어봅니다!

### 뷰티 업계로 비유하면...

팀장이 디자이너에게 이렇게 말하는 것과 같아요:

> "신제품 소개 카드 좀 만들어줘. 브랜드명이랑 제품명, 핵심 성분 넣으면 자동으로 예쁜 카드가 나오게."

이렇게 **말로 설명하면** AI가 만들어줍니다! 이것이 **Vibe Coding**이에요. 🎶
