# 🎤 첫 번째 프롬프트

> 🎯 AI에게 처음으로 도구 제작을 요청해봅시다!

## 오늘 만들 것: 제품 소개 카드 생성기

브랜드명, 제품명, 카테고리, 핵심 성분, 가격을 입력하면 → **예쁜 제품 소개 카드**가 나오는 HTML 도구!

### 완성 예시

> 입력: 브랜드=후, 제품명=천기단 화현, 카테고리=에센스, 핵심성분=녹용, 가격=350,000원
> 
> 출력: 고급스러운 디자인의 제품 소개 카드 (브라우저에서 바로 확인!)

## Step 1: AI에게 요청하기

Kiro 채팅창에 아래를 입력하세요:

```
화장품 제품 소개 카드 생성기를 HTML 파일 하나로 만들어줘.

입력 항목:
- 브랜드명 (예: 후, 숨37, 오휘)
- 제품명 (예: 천기단 화현 에센스)
- 카테고리 (예: 에센스, 크림, 토너)
- 핵심 성분 (예: 녹용, 산삼)
- 가격 (예: 350,000원)
- 한줄 설명 (예: 피부에 생기를 불어넣는 럭셔리 에센스)

요구사항:
- "생성" 버튼을 누르면 아래에 예쁜 제품 카드가 나타남
- 카드는 고급스러운 느낌 (그라데이션 배경, 그림자 효과)
- Tailwind CSS CDN 사용
- 별도 설치 없이 브라우저에서 바로 열 수 있게
- 파일명: product-card.html
```

## Step 2: 결과 확인하기

1. 왼쪽 파일 탐색기에서 `product-card.html` 파일이 생겼는지 확인
2. 파일을 **우클릭 → Open with Live Server** 또는 **파일 탐색기에서 더블클릭**
3. 브라우저에서 열리면 성공! 🎉

## Step 3: 테스트 해보기

아래 정보를 입력하고 "생성" 버튼을 눌러보세요:

| 항목 | 입력 값 |
|------|---------|
| 브랜드명 | 후 |
| 제품명 | 천기단 화현 에센스 |
| 카테고리 | 에센스 |
| 핵심 성분 | 녹용, 산삼, 사향 |
| 가격 | 350,000원 |
| 한줄 설명 | 피부에 왕실의 생기를 불어넣는 럭셔리 에센스 |

## 💡 잘 안 되면?

AI가 만든 결과가 기대와 다르면, **그냥 말로 수정 요청**하면 됩니다!

예시:
- "카드 배경을 좀 더 어두운 톤으로 바꿔줘"
- "폰트 크기가 너무 작아, 좀 키워줘"
- "카드 아래에 '공유하기' 버튼도 추가해줘"

> 🎯 **핵심**: 완벽하지 않아도 됩니다. 수정은 다음 단계에서 배웁니다!
