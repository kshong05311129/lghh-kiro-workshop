# Module 6: MCP 연동

## 🎯 이번 모듈의 목표

AI에게 **외부 도구를 연결**해서 더 강력하게 만들어봅시다!

## 🤔 MCP란?

**MCP (Model Context Protocol)** = AI에게 새로운 능력을 부여하는 방법

### 뷰티 업계로 비유하면

> BM이 아무리 뛰어나도, **시장 리서치 DB나 트렌드 리포트에 접근 못하면** 경쟁사 분석도, 시장 트렌드 파악도 제한적이죠.

MCP는 AI에게 **외부 자료에 직접 접근할 수 있는 권한을 주는 것**과 같습니다!

## 📱 MCP 없는 AI vs MCP 있는 AI

| 상황 | MCP 없음 | MCP 있음 |
|------|---------|---------|
| "Amazon Bedrock 사용법 알려줘" | 학습된 옛날 정보만 답변 | **공식 문서 직접 검색**해서 정확한 답변 |
| "S3에 이미지 저장하는 법" | 기억에 의존한 부정확한 답변 | **공식 문서 기반** 단계별 안내 |
| "Lambda 제한 시간은?" | 오래된 정보일 수 있음 | **최신 문서** 기반 정확한 답변 |

오늘은 **AWS 문서 MCP**를 연결해서 AI가 공식 문서를 검색할 수 있게 만들겠습니다.

**활용 예시:**
