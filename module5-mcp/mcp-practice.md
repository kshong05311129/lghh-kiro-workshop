# 🔌 MCP 활용 실습

> 🎯 MCP를 활용해서 AI가 공식 문서를 검색하는 체험을 해봅시다! (15분)

## 실습 1: MCP 있을 때 vs 없을 때 비교

### 질문 1: AWS 서비스 정보

채팅에 입력:

```
Amazon Bedrock에서 사용 가능한 모델 목록을 최신 공식 문서에서 찾아줘
```

> 💡 MCP 덕분에 AI가 **실시간으로 AWS 공식 문서를 검색**해서 최신 정보를 알려줍니다!

### 질문 2: 기술 가이드

```
AWS Lambda 함수의 메모리 및 타임아웃 제한에 대해 공식 문서 기반으로 알려줘
```

### 질문 3: 실무 질문

```
Amazon S3에 이미지를 업로드하고 CloudFront로 배포하는 방법을 공식 문서에서 찾아서 단계별로 정리해줘
```

## 실습 2: NPL 프로젝트와 연결해서 생각하기

> 🧴 앞으로 LG생활건강 NPL 프로젝트에서 이런 AWS 서비스들이 활용될 예정입니다.

### 질문 4: AI 서비스 활용

```
Amazon Bedrock으로 텍스트 생성 API를 호출하는 방법을 공식 문서에서 찾아줘.
우리가 제품 정보를 입력하면 마케팅 카피를 자동 생성하는 시스템을 만들고 싶어.
```

### 질문 5: 데이터 저장

```
Amazon DynamoDB에 제품 정보(브랜드, 제품명, 카테고리, 가격)를 저장하는 테이블 설계 방법을 공식 문서에서 찾아줘
```

### 질문 6: 파일 처리

```
AWS Lambda와 S3를 연동해서, CSV 파일이 업로드되면 자동으로 처리하는 방법을 공식 문서에서 찾아줘
```

## 💡 MCP의 핵심 가치

| 구분 | MCP 없이 | MCP 있으면 |
|------|---------|-----------|
| 정보 출처 | AI의 학습 데이터 (과거) | **공식 문서** (최신) |
| 정확도 | 때때로 부정확 | 출처 명확, 검증 가능 |
| 활용 | 일반적인 답변 | **실무에 바로 적용** 가능한 답변 |

## 🔮 앞으로의 가능성

> MCP는 AWS 문서뿐만 아니라 **다양한 외부 시스템을 연결**할 수 있습니다:

| MCP 종류 | 활용 예시 |
|----------|-----------|
| AWS 문서 | 기술 문서 검색 |
| 데이터베이스 | 사내 DB 직접 조회 |
| 웹 검색 | 실시간 시장 트렌드 검색 |
| Slack/Teams | 메시지 전송 자동화 |
| Jira/노션 | 프로젝트 관리 연동 |

> 🧴 **NPL 프로젝트에서의 활용**: 향후 PLM 시스템, 제품 DB, 시장 데이터를 MCP로 연결하면, AI가 직접 데이터를 조회해서 NPL Report를 자동 작성할 수 있습니다!
