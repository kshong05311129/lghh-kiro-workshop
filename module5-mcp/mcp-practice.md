# 🔌 MCP 활용 실습

> 🎯 MCP를 활용해서 AI가 실시간 웹 정보를 검색하는 체험을 해봅시다! (15분)

## 실습 1: MCP 있을 때 vs 없을 때 비교

### 질문 1: 경쟁사 제품 리뷰

채팅에 입력:

```
설화수 자음생 에센스 최신 리뷰를 웹에서 검색해서 요약해줘
```

> 💡 MCP 덕분에 AI가 **실시간으로 웹을 검색**해서 최신 후기와 반응을 알려줍니다!

### 질문 2: 트렌드 파악

```
2026년 K-beauty 성분 트렌드를 웹에서 검색해서 정리해줘
```

### 질문 3: 실무 질문

```
SK-II 페이셜 트리트먼트 에센스와 후 천기단 화현 에센스에 대한 소비자 반응을 각각 검색해서 비교해줘
```

### 질문 4: 시장 반응 조사

```
최근 출시된 럭셔리 한방 스킨케어 제품에 대한 소비자 반응을 웹에서 검색해서 정리해줘.
새로운 에센스 라인 기획에 참고하고 싶어.
```

### 질문 5: 경쟁 구도 파악

```
신제품 개발에 참고할만한 내용으로 정리해줘
```

## 💡 MCP의 핵심 가치

| 구분 | MCP 없이 | MCP 있으면 |
|------|---------|-----------|
| 정보 출처 | AI의 학습 데이터 (과거) | **실시간 웹 검색** (최신) |
| 정확도 | 때때로 부정확 | 출처 명확, 검증 가능 |
| 활용 | 일반적인 답변 | **실무에 바로 적용** 가능한 답변 |

## 🔮 앞으로의 가능성

> MCP는 웹 검색뿐만 아니라 **다양한 외부 시스템을 연결**할 수 있습니다:

| MCP 종류 | 활용 예시 |
|----------|-----------|
| 웹 검색 | 실시간 시장 트렌드/리뷰 검색 |
| AWS 문서 | 기술 문서 검색 |
| 데이터베이스 | 사내 DB 직접 조회 |
| Slack/Teams | 메시지 전송 자동화 |
| Jira/노션 | 프로젝트 관리 연동 |

> 🧴 **NPL 프로젝트에서의 활용**: 향후 PLM 시스템, 제품 DB, 시장 데이터를 MCP로 연결하면, AI가 직접 데이터를 조회하고 실시간 시장 반응까지 검색해서 NPL Report를 자동 작성할 수 있습니다!
