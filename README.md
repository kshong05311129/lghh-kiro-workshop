## 🤔 이런 분들을 위한 워크샵입니다

- ✅ 코딩을 한 번도 해본 적 없는 분
- ✅ 엑셀 정도는 쓸 줄 아는 분
- ✅ 반복 업무를 줄이고 싶은 분
- ✅ AI 도구에 관심 있는 분
- ✅ "개발자 없이도 뭔가 만들 수 있을까?" 궁금한 분

## 💡 오늘 만들어볼 것들

뷰티 업무에서 바로 쓸 수 있는 도구들입니다:

| 도구 | 활용 예시 |
|------|-----------|
| 🧴 제품 소개 카드 생성기 | 브랜드/제품명/효능 입력하면 소개 카드 자동 완성 |
| 📊 제품 매출 분석 대시보드 | CSV 데이터로 브랜드별 매출 차트 생성 |
| 🔍 경쟁사 비교 분석 도구 | 자사 vs 경쟁사 비교 테이블 자동 생성 |
| 📋 타겟 고객 페르소나 카드 | 타겟 정보 입력하면 페르소나 카드 생성 |
| 📝 마케팅 카피 생성기 | 제품 특징 입력하면 마케팅 카피 자동 작성 |
